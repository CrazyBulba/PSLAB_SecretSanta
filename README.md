# Бот для Тайного Санты в Telegram

Простой бот для организации розыгрыша «Тайный Санта» с поддержкой нескольких игр, инлайн-меню, повторным розыгрышем, сохранением состояния, избеганием повторений и вступительным сообщением.

**Текущая версия:** 1.7.0 (см. файл `VERSION`)

## Возможности

- Создание нескольких игр одним организатором
- **Вступительное сообщение** — участники видят его при вступлении
- **Инлайн-меню** с кнопками для выбора игры
- **Меню команд** в Telegram
- Присоединение по GameID
- Указание пожеланий к подарку
- Справедливый розыгрыш (никто не получает сам себя)
- **Повторный розыгрыш** (`/draw`)
- **Избегание повторения прошлых пар** (по username)
- **Экспорт текущей жеребьёвки** (`/export`)
- Отдельное закрытие игры (`/close`)
- Сохранение состояния между перезапусками
- Личные уведомления и автодосылка

## Вступительное сообщение

При создании игры можно сразу указать текст:
```
/create Дорогие друзья! В этом году бюджет до 3000 рублей. Пожелания пишите до 15 декабря.
```

Или задать/изменить позже:
```
/setintro Ваш текст здесь
```

Участник увидит это сообщение сразу после `/join`.

## Избегание прошлых пар

1. `/avoid on`
2. `/import_previous @alice:@bob @charlie:@dave` или `/import_from OLDGAMEID`
3. `/draw` будет избегать этих пар.

## Экспорт

`/export` — выдаёт пары в формате для `/import_previous`.

## Команды

- `/start`, `/help`
- `/create [текст]` — создать игру (опционально со вступительным)
- `/setintro [GameID] текст` — задать вступительное
- `/join GameID`
- `/mygames`
- `/setwish [GameID] текст`
- `/participants [GameID]`
- `/draw [GameID]`
- `/export [GameID]`
- `/close [GameID|all]`
- `/avoid [GameID] on|off`
- `/import_previous [GameID] @a:@b ...`
- `/import_from [GameID] OLD`
- `/myresult`
- `/info`

## Сохранение данных (для Railway)

Бот сохраняет игры в `games.json`. Для постоянства на Railway прикрепите Volume с mount path `/data`.
