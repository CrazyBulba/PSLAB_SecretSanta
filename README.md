# Secret Santa Telegram Bot

**Версия:** 1.8.0

Рефакторинг: логика вынесена в `GameManager`, единый выбор игры через `select_game`, команды стали тоньше. Легче добавлять новые фичи.

## Основные команды

- `/create [текст]` — создать игру (опционально со вступительным)
- `/setintro [текст]` — задать/изменить вступительное
- `/join CODE` — вступить (показывает intro)
- `/mygames` — список игр с кнопками
- `/setwish [текст]` — пожелания
- `/participants` — список (орг)
- `/draw` — розыгрыш
- `/export` — экспорт пар для следующего года
- `/close [all]` — закрыть
- `/avoid on|off` — режим избегания прошлых пар
- `/import_previous @a:@b ...` — загрузить запрещённые пары
- `/import_from OLDCODE` — импорт из другой игры
- `/myresult` — получить результат
- `/info` — статистика

## Архитектура (v1.8.0)

- `GameManager` — хранение, загрузка/сохранение, создание/вступление
- `select_game()` — единый выбор игры (аргумент или клавиатура)
- Команды минимальны, бизнес-логика в менеджере
- Легко добавлять новые команды и кнопки

## Persistence

Файл `games.json` в `/data` (Railway Volume) или в текущей директории.
