# Бот для Тайного Санты в Telegram

Простой бот для организации розыгрыша «Тайный Санта».

## Возможности

- Создание игры с уникальным кодом
- Присоединение по коду
- Указание пожеланий к подарку
- Просмотр списка участников (для организатора)
- Справедливый розыгрыш (никто не получает сам себя)
- Личные уведомления каждому участнику

## Установка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env`:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```

4. Запустите:
   ```bash
   python secret_santa_bot.py
   ```

## Команды

- `/start` или `/help` — помощь
- `/create` — создать игру
- `/join КОД` — присоединиться
- `/setwish ваши пожелания` — указать, что хотите получить
- `/participants` — список участников (только организатор)
- `/draw` — провести розыгрыш (только организатор)

## Важно

Данные хранятся в памяти. При перезапуске бота игры пропадают.  
Для постоянного использования рекомендуется добавить базу данных (SQLite, PostgreSQL и т.д.).

Участники должны начать диалог с ботом (написать /start), иначе бот не сможет отправить им личное сообщение.
