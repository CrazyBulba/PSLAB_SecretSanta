# Бот для Тайного Санты в Telegram

Простой бот для организации розыгрыша «Тайный Санта» с поддержкой нескольких игр, инлайн-меню выбора, повторным розыгрышем и сохранением состояния.

**Текущая версия:** 1.3.0 (см. файл `VERSION`)

## Возможности

- Создание нескольких игр одним организатором
- **Инлайн-меню** с кнопками для выбора игры
- Присоединение по уникальному коду
- Просмотр своих игр (`/mygames`)
- Управление конкретной игрой через код или кнопки
- Указание пожеланий к подарку
- Просмотр списка участников (для организатора)
- Справедливый розыгрыш (никто не получает сам себя)
- **Повторный розыгрыш** сколько угодно раз (`/draw`)
- **Отдельное закрытие** игры командой `/close`
- **Сохранение состояния** между перезапусками (файл `games.json`)
- Личные уведомления
- Автоматическая досылка результата
- Команда `/info` — версия и статистика

## Установка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env`:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```

4. Запустите:
   ```bash
   python secret_santa_bot.py
   ```

## Команды

- `/start` или `/help` — помощь
- `/create` — создать игру
- `/join КОД` — присоединиться
- `/mygames` — список ваших игр (с кнопками)
- `/setwish [КОД] ваши пожелания` — указать пожелания
- `/participants [КОД]` — список участников (только организатор)
- `/draw [КОД]` — провести или перекрутить розыгрыш (организатор)
- `/close [КОД]` — закрыть игру (организатор)
- `/myresult` — получить свой результат
- `/info` — версия бота, время работы и статистика

Если у вас только одна игра — код можно не указывать. Если несколько — появится меню с кнопками.

## Сохранение данных (для Railway)

Бот сохраняет игры в файл `games.json`.

Чтобы данные не пропадали при перезапусках на Railway:

1. В Railway прикрепите **Volume** к сервису (правый клик по сервису → Attach Volume).
2. Укажите mount path: `/data`
3. При желании можно задать переменную `DATA_DIR=/data`

Без Volume данные тоже сохраняются в файл, но пропадут при пересборке контейнера.

## Версии

Версия хранится в файле `VERSION` в корне репозитория. Бот читает её при запуске.

## Важно

- Если бот не смог отправить результат сразу, он отправит его автоматически, как только участник напишет боту любое сообщение в личку.
- После `/draw` можно крутить ещё раз. Чтобы окончательно закрыть игру — используйте `/close`.
