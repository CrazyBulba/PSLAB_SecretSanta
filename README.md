# Бот для Тайного Санты в Telegram

Простой бот для организации розыгрыша «Тайный Санта» с поддержкой нескольких игр, инлайн-меню, повторным розыгрышем, сохранением состояния и избеганием повторения прошлых пар.

**Текущая версия:** 1.6.1 (см. файл `VERSION`)

## Возможности

- Создание нескольких игр одним организатором
- **Инлайн-меню** с кнопками для выбора игры
- **Меню команд** в Telegram
- Присоединение по GameID
- Указание пожеланий к подарку
- Справедливый розыгрыш (никто не получает сам себя)
- **Повторный розыгрыш** (`/draw`)
- **Избегание повторения прошлых пар** (по username)
- **Экспорт текущей жеребьёвки** (`/export`) — для загрузки в следующем году
- Отдельное закрытие игры (`/close`)
- Сохранение состояния между перезапусками
- Личные уведомления и автодосылка

## Избегание прошлых пар

1. Включите режим:
   ```
   /avoid on
   ```
2. Загрузите прошлые пары:
   ```
   /import_previous @alice:@bob @charlie:@dave
   ```
   или из другой игры:
   ```
   /import_from OLDGAMEID
   ```
3. При `/draw` бот будет избегать этих пар.

## Экспорт жеребьёвки

После розыгрыша организатор может экспортировать пары:
```
/export
```
Бот выдаст текст вида `@user1:@user2 @user3:@user4 ...`, который можно скопировать и в следующем году вставить в `/import_previous`.

## Команды

- `/start`, `/help` — помощь
- `/create` — создать игру
- `/join GameID` — присоединиться
- `/mygames` — список игр
- `/setwish [GameID] текст` — пожелания
- `/participants [GameID]` — участники
- `/draw [GameID]` — розыгрыш
- `/export [GameID]` — экспорт жеребьёвки
- `/close [GameID|all]` — закрыть
- `/avoid [GameID] on|off` — режим избегания
- `/import_previous [GameID] @a:@b ...` — загрузить пары
- `/import_from [GameID] OLD` — импорт из другой игры
- `/myresult` — получить результат
- `/info` — статистика бота

## Сохранение данных (для Railway)

Бот сохраняет игры в `games.json`. Для постоянства на Railway прикрепите Volume с mount path `/data`.
