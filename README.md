# Secret Santa Telegram Bot

**Версия:** 1.10.0

## Формат сообщения в /mygames

При выборе игры показывается:

```
📝 Вступительный текст
💰 Сумма на подарок: 3000 рублей
🆔 ID: ABC123

── Участник ──
🎁 Подопечный: Иван @ivan
💬 Подопечный желает: книга по Python
✨ Мое желание: наушники
👥 Участников: 8

── Организатор ──
🎲 Розыгрыш: да
🛡 Избегать: вкл (3 пар)
```

## Команды

- `/create` — создать (бот спросит вступительное)
- `/setintro` — задать вступительное
- `/setamount` — указать сумму на подарок
- `/join CODE` — вступить
- `/mygames` — список игр (только активные)
- `/setwish` — пожелания
- `/draw` — розыгрыш
- `/close [all]` — удалить игру
- `/avoid on|off` — избегать прошлые пары
- `/export` — экспорт для следующего года

## Persistence

`games.json` в `/data` (Railway Volume).
